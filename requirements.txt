# Runtime dependencies for the Facial Expression Recognition backend.
# Pinned to the versions this project is known to work with.
#
# This file is used BOTH by local development and by the Vercel Python
# function. The environment markers below are what let one file serve both:
#
#   * torch/torchvision are installed ONLY on Linux, from the CPU index. On
#     Windows the markers skip them entirely, so running `pip install -r` on a
#     development machine never replaces a working CUDA build with a CPU one.
#     Install torch locally via setup_backend.bat / SETUP_WINDOWS.md as before.
#
#   * OpenCV is headless on Linux. The regular wheel links against libGL.so.1,
#     which a serverless image does not ship, and the import fails at cold
#     start with no obvious cause. Both distributions provide `cv2`.
